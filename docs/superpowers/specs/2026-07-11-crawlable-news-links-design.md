# Crawlable News Links — Design

**Date:** 2026-07-11
**Status:** Approved pending user review

## Problem

Google has indexed only one article in `/news/`. The raw HTML served for
`news/index.html` contains zero `<a>` links to articles — the listing grid,
category filters, and pagination are all rendered client-side from the
`NEWS_POSTS` array in `news-data.js`. The home-page carousel is JS-rendered
too. Discovery therefore relies on `sitemap.xml` alone, which is the weakest
signal, and articles sit unindexed ("Discovered – currently not indexed").
Cross-links between articles are also nearly absent (one link total across
five articles), despite the CLAUDE.md rule requiring 2–3 per article.

Constraint: the site deliberately has no build step. Push to `main` FTP-deploys
files as-is. The fix must not add a deploy-time build, and the user must not
have to run anything manually.

## Solution overview

Three parts:

1. A generator script, `generate-news-links.py`, that writes a static block of
   article links into `news/index.html` from `news-data.js`.
2. Automation so Claude runs it — a Claude Code hook that fires whenever
   `news-data.js` is edited, plus a CLAUDE.md checklist step documenting it.
   The user never runs the script.
3. Contextual cross-links added to the five existing articles.

`news-data.js` stays the single source of truth. Deploy is unchanged.

## Part 1 — Generator script

`generate-news-links.py` (repo root, next to `generate-article-audio.py`):

- Reads `news-data.js` and extracts `slug`, `title`, and `dateDisplay` for
  each post using a strict parse of the known field format.
- **Fails loudly** (non-zero exit, clear message) if any post is missing one
  of those fields or if the markers below are absent. Never silently skips.
- Rewrites everything between two marker comments inside the `#ns-grid` div
  in `news/index.html`:

```html
<div class="ns-grid" id="ns-grid" aria-label="News posts">
  <!-- static-news:start — generated by generate-news-links.py, do not edit by hand -->
  <a href="/news/ai-music-88-million-views">What Happens When Your AI Songs Get 88 Million Views (27 April 2026)</a>
  <!-- ... one per article, newest first ... -->
  <!-- static-news:end -->
</div>
```

- Idempotent: running it twice produces identical output.
- Links are plain visible anchors (hidden links are discounted by Google).
  The existing `render()` replaces the grid's innerHTML on load, so users see
  today's card layout; with JS off, visitors get a usable plain link list.
- No CSS or JS files change, so no `?v=` bumps.

## Part 2 — Automation

**Hook (safety net):** a `PostToolUse` hook in the project's
`.claude/settings.json` matching `Edit|Write`; when the edited file is
`news-data.js`, it runs `python generate-news-links.py`. Fires mechanically in
any Claude Code session that touches the posts array. Configured via the
update-config skill at implementation time; must work on Windows (PowerShell
host).

**CLAUDE.md (documentation):** the "After creating the article" checklist
gains a step: run `python generate-news-links.py` (Claude runs it — the hook
normally does this automatically) and commit the regenerated
`news/index.html`.

## Part 3 — Cross-links between existing articles

Each of the five articles gets 2–3 contextual in-body links to related
articles or tools:

- Descriptive anchor text, UK English, placed early where the topic naturally
  arises; no page linked twice in one article.
- Natural pairs: ai-music ↔ geo-generative-engine-optimisation (distribution/
  discoverability), geo ↔ ai-terms-explained, claude-code-vsc ↔
  ai-terms-explained. Exact placements decided per-article during
  implementation.
- Every edited article's `dateModified` in its Article JSON-LD is bumped to
  the edit date, per the existing CLAUDE.md rule.

## Out of scope

- Home-page carousel static rendering (marginal benefit; listing page covers
  discovery).
- Making `news/index.html` filters/pagination work without JS.
- Search Console actions (user requests indexing after deploy).

## Verification

1. Run the script; confirm the static block lists all five articles, newest
   first, and a second run produces no diff.
2. Edit `news-data.js` trivially in-session; confirm the hook fires and
   regenerates the block.
3. Load `news/index.html` with JS disabled → plain link list visible; with JS
   → cards, filters, pagination behave exactly as today.
4. After push, `curl https://johnb.io/news/` and confirm the `<a>` tags are
   present in raw HTML.
